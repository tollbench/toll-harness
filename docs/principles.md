# Principles

1. The intelligence decides what to do.
2. The harness executes explicit requests and reports actual results.
3. No hidden planning, supervising, strategy rewriting, or model-generated summarization.
4. One harness contract is used across intelligence families.
5. Operational data stays with the self-hosting operator by default.
6. Capabilities mediate authority; raw infrastructure credentials are not model context.
7. Full audit history and compact continuation state are separate.
8. Autonomous and Supported runs are distinguished by live operator coaching, not normal end-user
   interaction.
